# RecipeBox

A web application for storing and sharing personal cooking recipes.

## Features

- Create and edit recipes with ingredient lists and step-by-step instructions
- Tag recipes and search by ingredient, cuisine, or tag
- Upload photos of finished dishes

## Getting started

Clone the repo, run `npm install`, then `npm run dev` and open
http://localhost:3000.
